# Восстановленный API главного меню

Проверенная сборка:

- Frostpunk `1.6.1`, GOG;
- SHA-256: `719c6e016bcdb1021a6401b1624aebdcfb03c6782a763d2fbd8c2805f9dae9d4`;
- preferred image base: `0x140000000`;
- ASLR учитывается: во время работы DLL использует `module base + RVA`.

## Главная панель

- vtable `FrostpunkUIMainMenuMainPanel`: RVA `0x204C488`;
- размер объекта: `0x110`;
- `+0xD0`: Continue;
- `+0xD8`: New Game;
- `+0xE0`: Load;
- `+0xE8`: Scenario;
- `+0xF0`: скрытый Custom Scenario;
- `+0xF8`: Endless;
- `+0x100`: DLC.

Каждое поле содержит указатель на holder, а первый qword holder указывает на
`UIButton`. Vtable `UIButton` имеет RVA `0x1D75E08`.

Для прототипа используется штатная строка Endless (`+0xF8`). Её основной
текстовый элемент называется:

- `MENU_OPTION_TEXT` — основной заголовок.

Опциональная золотая метка зависит от состояния профиля и может называться
`NEW_MAP_BOUGHT`, `JUST_UNLOCKED` или `STORY_UNLOCKED`. Узкие строки русской
сборки преобразуются как Windows-1251, поэтому русский текст нельзя передавать
в этот API как UTF-8.

## Использованные функции

| Назначение | RVA |
| --- | ---: |
| создание engine string | `0xE48BA0` |
| уничтожение engine string | `0xE47C30` |
| рекурсивный поиск дочернего UI-элемента | `0xF77CC0` |
| dynamic cast к `UIText` | `0x147B790` |
| установка текста `UIText` | `0x106B5F0` |
| установка видимости UI-элемента | `0xFCD9F0` |
| установка transform UI-элемента | `0x10504B0` |

## Перехваты

- создание/привязка кнопок главного меню: RVA `0x1A76B80`;
- обновление состояния главного меню: RVA `0x1A770F0`;
- общий callback пунктов меню: RVA `0x1A748E0`.

Идентификатор события Endless — `0x61` в поле `event + 0x18`, а штатной панели
Scenarios — `0x5B`. Мод перехватывает только `0x61`, подменяет его на `0x5B` и
открывает переиспользованную панель выбора подключения. Все остальные события
передаются оригинальному callback. Перед установкой каждого inline hook
проверяются точные байты пролога.

## Реализованный вертикальный срез

1. Переименовать штатный `ENDLESS_BUTTON` в `МУЛЬТИПЛЕЕР` без изменения его
   положения и размеров.
2. Перенаправить событие `0x61` на штатную панель Scenarios.
3. Переименовать заголовок панели в `ВЫБРАТЬ ПОДКЛЮЧЕНИЕ`.
4. Оставить в списке строки `STEAM` и `ЛОКАЛЬНАЯ СЕТЬ`, скрыв остальные сценарии и разделители.
5. Перехватить кнопку запуска, чтобы прототип не запускал сценарий `Новый дом`.

Файлы игры на диске не изменяются; DLL действует только в памяти запущенного
процесса.

## Ввод на строках подключения

Штатный CreateScenarioRow (`0x1A7AD20`) ищет `SCENARIO_BUTTON` внутри
`SCENARIO_BUTTON_WRAPPER`. Для заблокированных сценариев он отключает ввод,
применяет состояние `LOCKED` и **не регистрирует callback**. Одной видимости
или переименования `TITLE_TEXT` недостаточно.

- `SetButtonEnabled(button, enabled, animated)`: `0xFCD100`, enabled хранится
  в бите `0x8` DWORD `button + 0x270`.
- `BindButtonCallback(button, owner, callback, type, argument, flags)`:
  `0xFCCF20`; штатная привязка строки использует type=0, argument=index, flags=1.
  Функция не добавляет повторно идентичную привязку.
- `SetUiState`: `0xF75DA0`; состояния `LOCKED`, `SELECTED`, `UNSELECTED`.
- Callback строки: `0x1A7BAF0`, индекс из `event + 0x18`.

В режиме мультиплеера обе кнопки включаются и получают привязку callback.
Перехват сохраняет выбор транспорта в моде, не вызывает штатную проверку
прогресса/DLC, не выбирает настоящий сценарий. Вне мультиплеера callback
передаётся игре. При выходе восстанавливается исходное enabled/LOCKED состояние.
Нажатие строки сразу запускает форму; «ВЫБРАТЬ» дублирует это действие. Запуск:
`FrostConnectionUI.exe --lan|--steam --pid <GetCurrentProcessId()>`. Внешняя
немодальная форма получает имя и адрес, управляет дочерним сетевым мостом;
внутриигровой поток не ждёт её закрытия. Повторный запуск поднимает существующую
форму для данного PID. Если форма уже открыта, игровой обработчик сначала
находит её через FindWindowW, восстанавливает из свёрнутого состояния и передаёт
фокус. Для нового процесса также явно разрешается получение фокуса.

Проверка: `tests/MenuRoutingTests.cpp` (отдельный консольный exe, user32.lib)
проверяет Steam/LAN, невалидный индекс, отсутствие выбора и передачу штатных
сценариев оригинальному callback. В игре проверено нажатие LAN → «ВЫБРАТЬ» →
форму «FrostBridge — LAN». Два процесса запущены через лаунчер, DLL найдена в обоих.
