# Восстановленный API главного меню

Проверенная сборка:

- Frostpunk `1.6.1`, GOG;
- SHA-256: `719c6e016bcdb1021a6401b1624aebdcfb03c6782a763d2fbd8c2805f9dae9d4`;
- preferred image base: `0x140000000`;
- ASLR учитывается: во время работы DLL использует `module base + RVA`.

## Главная панель

- vtable `FrostpunkUIMainMenuMainPanel`: RVA `0x204C488`;
- размер объекта: `0x110`;
- `+0xD0`: Continue;
- `+0xD8`: New Game;
- `+0xE0`: Load;
- `+0xE8`: Scenario;
- `+0xF0`: скрытый Custom Scenario;
- `+0xF8`: Endless;
- `+0x100`: DLC.

Каждое поле содержит указатель на holder, а первый qword holder указывает на
`UIButton`. Vtable `UIButton` имеет RVA `0x1D75E08`.

Скрытая кнопка содержит текстовые элементы:

- `MENU_OPTION_TEXT` — основной заголовок;
- `STORY_UNLOCKED` — золотой подзаголовок.

Их исходные localization keys — `UI/Menu/MainPanel/CustomScenario` и
`UI/Menu/MainPanel/StoryUnlocked`. Узкие строки русской сборки преобразуются как
Windows-1251, поэтому русский текст нельзя передавать в этот API как UTF-8.

## Использованные функции

| Назначение | RVA |
| --- | ---: |
| создание engine string | `0xE48BA0` |
| уничтожение engine string | `0xE47C30` |
| рекурсивный поиск дочернего UI-элемента | `0xF77CC0` |
| dynamic cast к `UIText` | `0x147B790` |
| установка текста `UIText` | `0x106B5F0` |
| установка видимости UI-элемента | `0xFCD9F0` |
| установка transform UI-элемента | `0x10504B0` |

Вектор transform должен быть выровнен по 16 байт: функция загружает его через
SIMD-инструкцию `movaps`.

## Перехваты

- создание/привязка кнопок главного меню: RVA `0x1A76B80`;
- обновление состояния главного меню: RVA `0x1A770F0`;
- общий callback пунктов меню: RVA `0x1A748E0`.

Идентификатор события Custom Scenario — `0x60` в поле `event + 0x18`. Мод
перехватывает только этот ID; все остальные события передаются оригинальному
callback. Перед установкой каждого inline hook проверяются точные байты пролога.

## Реализованный вертикальный срез

1. Активировать скрытый `CUSTOM_SCENARIO_BUTTON`.
2. Установить заголовок `МУЛЬТИПЛЕЕР`.
3. Показать золотую метку `* НОВЫЙ CO-OP РЕЖИМ *`.
4. Через штатный setter перенести кнопку на 62 UI-единицы выше Continue.
5. По клику открыть тестовое окно FrostBridge, не вызывая старый сценарный callback.

Файлы игры на диске не изменяются; DLL действует только в памяти запущенного
процесса.
